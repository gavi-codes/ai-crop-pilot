# 🌱 AI CropPilot

### Smart Agriculture. Better Decisions. Higher Profits.

AI CropPilot is an AI-powered agricultural intelligence platform designed to help farmers make better decisions about crop prices, market selection, and selling strategies.

## 🚀 Key Features

- 🔐 **User Authentication** — User access and account management.
- 📈 **AI Crop Price Prediction** — Predict crop prices using machine learning.
- 🏪 **Best Market Recommendation** — Help farmers identify suitable markets.
- 💡 **AI Selling Advisor** — Provide intelligent selling suggestions.
- 🌦️ **Future Enhancements** — Crop disease detection, weather forecasting, soil analysis, fertilizer recommendations, and voice assistance.

## 🛠️ Technologies Used

- **Frontend:** React, Vite
- **Backend:** Python, Flask
- **Machine Learning:** Scikit-learn
- **Data Processing:** Pandas, NumPy
- **Database:** Supabase
- **Deployment:** Vercel

## 🎯 Project Objective

AI CropPilot aims to make agricultural information more accessible and support data-driven decisions for farmers, initially focusing on Karnataka, India.

## 🧠 How It Works

1. Collect and preprocess agricultural data.
2. Train a machine learning model using historical data.
3. Predict crop prices based on available features.
4. Help farmers compare market options and plan selling strategies.

## 🔮 Future Scope

- Crop disease detection
- Weather integration
- Soil analysis and fertilizer recommendations
- Government scheme recommendations
- AI chatbot and voice assistant
- Mobile application
- ## 📊 Dataset and Data Sources

AI CropPilot uses agricultural datasets obtained from [Kaggle](https://www.kaggle.com/) to support the development and evaluation of its crop price prediction model.

- **Data period:** 2024, 2025, and 2026
- **Source:** Kaggle
- **Purpose:** Agricultural data analysis, data preprocessing, and machine learning model development.
- **Usage:** The data is used to explore crop price patterns and develop price prediction capabilities for agricultural markets in Karnataka.

The datasets are cleaned and processed before being used for model training and evaluation. Dataset coverage and prediction performance depend on the available data and its quality.
