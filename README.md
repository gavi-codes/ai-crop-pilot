# 🌱 AI CropPilot

### Smart Agriculture. Better Decisions. Higher Profits.

AI CropPilot is an AI-powered agricultural intelligence platform designed to help farmers make better decisions about crop prices, market selection, and selling strategies.

## 🚀 Key Features

- 🔐 **User Authentication** — User access and account management.
- 📈 **AI Crop Price Prediction** — Predict crop prices using machine learning.
- 🏪 **Best Market Recommendation** — Help farmers identify suitable markets.
- 💡 **AI Selling Advisor** — Provide intelligent selling suggestions.
- 🌦️ **Future Enhancements** — Crop disease detection, weather forecasting, soil analysis, fertilizer recommendations, and voice assistance.

## 🛠️ Technologies Used

- **Frontend:** React, Vite
- **Backend:** Python, Flask
- **Machine Learning:** Scikit-learn
- **Data Processing:** Pandas, NumPy
- **Database:** Supabase
- **Deployment:** Vercel

## 🎯 Project Objective

AI CropPilot aims to make agricultural information more accessible and support data-driven decisions for farmers, initially focusing on Karnataka, India.

## 🧠 How It Works

1. Collect and preprocess agricultural data.
2. Train a machine learning model using historical data.
3. Predict crop prices based on available features.
4. Help farmers compare market options and plan selling strategies.
   ## 📊 Dataset Information and Sources

AI CropPilot uses agricultural data resources from Kaggle for data analysis and machine learning model development, with a focus on Karnataka, India.

### Data Sources

1. **Agriculture Dataset – Karnataka**
   - Source: [Kaggle Dataset](https://www.kaggle.com/datasets/imtkaggleteam/agriculture-dataset-karnataka)
   - Used as an agricultural data resource for model development.

2. **Karnataka Agriculture EDA Analysis**
   - Source: [Kaggle Notebook by Behrad Tabrizipour](https://www.kaggle.com/code/behradtabrizipour/karnataka-hindu-agriculture-eda-analysis)
   - Reference for Karnataka agriculture data analysis.

### Data Coverage

- **Years:** 2024, 2025, and 2026, as used in the project's collected data.
- **Geographical focus:** Karnataka, India.
- **Purpose:** Data preprocessing, agricultural analysis, and crop price prediction model development.

### Data Processing

The collected data is cleaned and prepared before being used for machine learning. The processed features are used to train and evaluate the crop price prediction model.

**Attribution:** The original datasets and notebook are credited to their respective Kaggle contributors. Please refer to the linked sources for their licensing and usage conditions.
